# IatTeste
Plugin para QGIS em Python para facilitar o fluxo de trabalho dos técnicos do Instituto Água e Terra.

É baseado ao redor de uma interface gráfica docável, que permite ao usuário pesquisar dentro de camadas por valores predeterminados.

Ele possui um sanitizador de entradas que permite ao técnico inserir os dados de forma habitual, incluindo pontos e traços, e automaticamente listar, em formato de tabela, os valores encontrados. Após, pode-se ir imediatamente ao ponto encontrado ao clicar na tabela.


Funções podem ser adicionadas conforme a demanda e viabilidade técnica.
